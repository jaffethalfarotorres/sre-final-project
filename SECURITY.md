# Security policy

This repository is a teaching lab for SRE learners. It runs on a local Minikube cluster and every credential in it
(for example the Grafana `admin` / `admin` login) is local-only and meant for the lab. Never reuse them elsewhere.

## Supported versions

Only the latest `main` and the latest release receive fixes.

## Reporting a vulnerability

Please report privately: open the repository **Security** tab, choose **Report a vulnerability**, and describe the
problem. Do not open a public issue for it.

## What to expect

We acknowledge reports within 7 days and tell you what we plan to do about them.
